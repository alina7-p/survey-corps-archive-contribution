# Survey Corps Archive

An unofficial *Attack on Titan* fan website for the Web Technologies endterm project, SE-2540. It presents the story, military branches, Titans, characters and episode guide across seven pages.

## Team

- Assem Tugelbay — home page and shared styles
- Zhansaya Boranbaikyzy — lore and Titan archive
- Alina Ibadulla — episode guide and enlist form

## Pages and features

- Home, Lore, Titan archive, Characters, Episodes, Sign in and Enlist pages with shared responsive navigation.
- Light/dark theme, demo sign-in, saved favourites, FAQ animations and validated forms.
- Titan search, filters, editable records and image gallery.
- Characters loaded from Jikan or AniList, with search, filters, profiles, favourites, cache and offline fallback.

## Run locally

Open `index.html` in a browser; no build step is needed. Characters requires internet for live data. Forms and sign-in are front-end demos: passwords and messages are not sent to a server.
